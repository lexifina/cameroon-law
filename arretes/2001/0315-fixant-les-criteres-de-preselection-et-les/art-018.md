# Article 18

Pour la sélection finale, le soumissionnaire retenu est celui qui aura obtenu le plus grand nombre de points après application de la formule ci-après :
N = (St x 30%) + (Sf x 70%) avec :
N = nombre de points du soumissionnaire St = score technique obtenu par le soumissionnaire exprimée par rapport à 100 Sf = score financier du soumissionnaire exprimé par rapport à 100.
Le score financier se calcule par la formule Sf = F/Fp x 100 avec :
F = offre financière du soumissionnaire considéré ;
Fp = offre financière la plus élevée parmi les soumissionnaires retenus à l’article 15 ci-dessus, pour la vente de coupe ou pour la concession considérée.
