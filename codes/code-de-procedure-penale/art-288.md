# Article 288

(1) Une juridiction de jugement est un organe chargé de statuer conformément à la loi sur les faits dont elle est saisie et de prononcer, le cas échéant, les peines et mesures prévues par la loi. (2) Dans le présent Code, constituent des juridictions de jugement de droit commun :
a) le Tribunal de Première Instance ;
b) le Tribunal de Grande Instance ;
c) la Cour d'Appel ;
d) la Cour Suprême.
