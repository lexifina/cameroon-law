# Article 296

(1) Le Tribunal de Première Instance est compétent pour statuer sur toutes les exceptions soulevées par les parties à l'exclusion des exceptions préjudicielles. (2)
a) Lorsqu'une exception préjudicielle est admise, le Tribunal de Première Instance doit surseoir à statuer jusqu'à ce que la juridiction compétente se prononce sur cette exception ;
b) Le Tribunal impartit à l'auteur de l'exception un délai pour saisir la juridiction compétente ;
c) Si l'action n'est pas introduite dans ce délai, il est passé outre l'exception, à moins que la partie qui l'a soulevée ne justifie son inaction. (3) Si l'exception n'est pas admise, les débats continuent.
