# Article 376

Les seuls actes dont les préposés pourront demander communication dans les administrations locales et municipales sont ceux dénommés à l’Article 270 du présent Code.
Article 377.- Les dépositaires de registres des magasins généraux sont tenus de les communiquer aux agents des Impôts dans le Code prescrit par l’Article 376 ci-dessus et sous les peines y énoncées.
