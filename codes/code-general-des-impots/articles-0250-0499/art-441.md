# Article 441

Dans tous les cas où le présent Code permet ou impose l’usage d’un timbre mobile, l’oblitération de ce timbre doit être faite par les officiers ministériels ou fonctionnaires publics pour les actes publiés et par les parties pour les actes privés non soumis obliga- toirement à la formalité de l’enregistrement.
Pour les pièces qui, par leur nature doi- vent être soumises à une administration, l’oblitération est effectuée à la dili- gence de ladite administration.
