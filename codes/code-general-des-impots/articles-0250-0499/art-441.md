# Article 441

Dans tous les cas où le présent Code permet ou impose l’usage d’un timbre mobile, l’oblitération de ce timbre doit être faite par les officiers ministériels ou fonctionnaires publics pour les actes publiés et par les parties pour les actes privés non soumis obligatoire- ment à la formalité de l’enregistrement.
Pour les pièces qui, par leur nature doivent être soumises à une adminis- tration, l’oblitération est effectuée à la diligence de ladite administration.
