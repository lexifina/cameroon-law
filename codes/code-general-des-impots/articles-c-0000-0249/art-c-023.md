# Article C 23

Tout contribuable qui n’a pas acquitté sa patente dans le délai ou qui n’a pas fourni dans le même délai, les renseignements nécessaires à l’établissement de celle-ci est passible d’une pénalité de dix pour cent (10 %) par mois de retard, avec un maximum de trente pour cent (30 %) de l’impôt dû.
