# Article 83

Obéissance a l'autorité légale (1) La responsabilité pénale ne peut résulter d'un acle accompli sur les ordres d'une autorité compétente a laquelle l'obéissance est légitimement due. (2) Les dispositions de l'alinéa 1°' ci-dessus ne sont toutefois pas applicables si l'ordre est manifestement illégitime.
