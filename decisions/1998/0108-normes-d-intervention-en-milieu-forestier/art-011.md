# Article 11

Le titulaire d'un titre d'exploitation forestière ne peut effectuer des activités d'aménagement forestier sur les unités territoriales suivantes:
1° Les aires protégées pour la faune:
- les parcs nationaux,
- les réserves de faune,
- les zones d'intérêt cynégétique,
- les game-ranches appartenant à l'État,
- les jardins zoologiques,
- les sanctuaires de faune;
2° Les réserves forestières:
- les réserves écologiques intégrales,
- les forêts de protection,
- les forêts de récréation,
- les forêts d'enseignement et de recherche, - les sanctuaires de flore,
- les jardins botaniques,
3° Les zones tampons.
