# Article 13

Le périmètre sur lequel porte l’Autorisation de Prospection peut faire l’objet de négociations portant sur l’attribution d’un Contrat Pétrolier.
Si ces négociations aboutissent, l’Autorisation de Prospection devient caduque de plein droit dans les trente jours suivant la conclusion du Contrat Pétrolier concerné, sauf si un délai supplémentaire est nécessaire pour achever des travaux en cours.
