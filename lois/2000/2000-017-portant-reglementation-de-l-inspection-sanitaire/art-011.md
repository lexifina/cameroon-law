# Article 11

Sont réputées zoonoses, infections, intoxications et infections graves, les maladies ci-après désignées :
1. la rage chez toutes les espèces ;
2. la tuberculose et la pseudo-tuberculose chez toutes les espèces ;
3. le charbon bactérien chez les équidés, porcins et ruminants ;
4. les brucelloses chez les bovidés, petits ruminants et porcins ;
 les pasteurelloses ;
 l’érisipelothrix ;
 la listerellose (listériose) ;
 les vibrioses chez les ruminants ;
 les salmonelloses ;
 les taeniasis ;
 la trichinose ;
 la toxoplasmose ;
 la distomatose ;
 la sarcosporidiose ;
 les myases intestinales ;
 les shigelloses ;
 les clamydoses ;
 la fièvre Q ;
 l’ornithose aviaire ;
 la psittacose ;
 la leptospirose ;
 le botulisme ;
 l’échinococcose ;
