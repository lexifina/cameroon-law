# Article 28

(1) Les forêts domaniales sont celles qui bénéficient d'un décret de classement au domaine privé de l'Etat.
(2) Sont consi.dérées comme forêts domaniales:
a) les forêts de production telles que les Unités Forestières d'Aménagement (UFA)
b) les aires protégées ci-après :
les parcs nationaux
- les réserves écologiques intégrales;
- les réserves de faune ;
- les sanctuaires de faune;
- les Zones d'intérêt Cynégétique (ZlC);
- les game-ranch appartenant à l'Etat ;
- les jardins zoologiques appartenant à l'Etat ;
- les sanctuaires de flore ;
- les jardins botaniques appartenant à l'Etat ;
- les aires marines protégées.
c) les réserves forestières ci-après :
- les forêts de conservation ;
- les forêts de protection ;
- les forêts de récréation ;
- les forêts d'enseignement et de recherche ;
les périmètres de reboisement.
